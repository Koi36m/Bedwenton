# Arcane Halo K1.1 visual polish

Authority: the owner request preserved exactly in `k1.1/OWNER-AUTHORIZATION.txt`.
Base: native K1 implementation `632e3564420db67209cc1babc8b2039c80badd6f`, evidence checkpoint
`738dbd3d449d2f15c2a524793d447b11e3184211`. Original K1 source, tests, report and design remain in Git history.
This additive note supersedes their visual values only for K1.1; it does not revise engine contracts.

The full white waist circle becomes a rear crescent centered on local -Z (behind the player's body).
The radius remains 0.9 blocks and height remains feet +1.0. Simple is a narrow 120-degree arc; Balanced is 160 degrees;
Heavy extends 200 degrees around the back and sides. Both endpoints are sampled, uniformly along the arc.
Simple/Balanced stay entirely behind the body throughout animation. Heavy retains at least 13 of its 16 waist points
behind the body and leaves the forward-facing 144-degree wedge empty even at maximum sway.

| Tier | K1 waist + halo | K1.1 waist + halo | New total | Waist arc |
|---|---:|---:|---:|---:|
| Simple | 12 + 0 | 8 + 0 | 8 | 120 degrees |
| Balanced | 18 + 9 | 12 + 6 | 18 | 160 degrees |
| Heavy | 24 + 12 | 16 + 8 | 24 | 200 degrees |

Total points/reservations decrease by one third at every tier. The waist continues to use M7's native END_ROD style.
The cyan DUST keeps RGB `0x5CE1FF`, radius 0.45 and height feet +2.15. Its size decreases from 0.7 to 0.55 and counts
from 9/12 to 6/8, increasing separation and reducing crowding. Height is deliberately unchanged; no unverified
nameplate-clearance improvement is claimed. Existing style keys and the two-layer structure are retained.

A rear crescent cannot keep revolving through the player's front and remain rear-biased. The waist therefore keeps
the existing deterministic 60-tick animation period as a gentle -8 to +8 degree sway: `Timing.pingPong(30)` drives
`Motion.spin(+Y, 16/360 turns, phase -8/360, SMOOTHSTEP)`. It starts at -8 degrees, reaches +8 at local tick 30,
and returns at tick 60 without a positional jump or sharp turnaround. The cyan halo keeps its original opposite
80-tick full rotation. Both still derive time from the aura's original GAME start tick and follow current body yaw.

The existing circular-family `Spiral.arc` API is reused for a **constant-radius, zero-rise planar arc**; there is no
spiral visual behavior. Recipes/shapes are still built once per session. No lifecycle, commands, default tier,
permissions, snapshot validation, scheduler, capacity, budget policy or emitter behavior changes. Simple remains the
configured default; Balanced is the fuller presentation to try visually. No sparkle nodes, new layers or particle families.

Six existing K1 test files update only affected visual formulas, centroid expectations, counts and DUST size.
All 57 K1 tests remain; all 526 M1–M6/M7/K0 tests are byte-identical. Six new production tests check rear bias/front
clearance over phases/yaws, exact endpoints/spacing, rear centroid, smooth turnarounds, halo separation and budget thinning.
The expected complete suite is 589 tests. Exact test diffs and frozen-file checksums are provided in the K1.1 evidence.

Visual elegance, native particle persistence and nameplate interaction require a new in-game assessment. K1's
owner-reported in-game behavior/performance is historical K1 evidence, not a K1.1 pass. All new K1.1 server smoke
checks remain NOT RUN unless separately recorded. No release or live deployment is authorized.

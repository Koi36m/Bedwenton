# K1.2.2 implementation review report

**READY FOR INDEPENDENT K1.2.2 IMPLEMENTATION REVIEW.** Acceptance and Minecraft visual review remain pending.

White END_ROD outline and strokes now emit at effect ages 0, 4, 8, ... instead of every tick. The cyan halo emits every
tick as before. AuraSession caches the original full recipe and one halo-only recipe, reusing the exact original halo
Layer objects. AuraEffect selects the appropriate recipe after existing identity/lifecycle validation. There is no new
task, timer, clock, layer, particle family, dependency, public API, emitter path or change to the shared scheduler.

The full AuraRecipe geometry factory is unchanged byte-for-byte (apart from the additive helper/import): radius 1.05,
rear offset 0.85, center height 1.25, stable vertical outline, same cubic controls and 80-tick inner rotation. The same
Playback, now and frameOrdinal are retained on quiet ticks. Missing/rejected ticks do not pause or restart the phase,
and do not produce catch-up bursts. Replacement starts a new effect at age zero. Vanilla END_ROD lifetime is unchanged;
Paper exposes no ordinary per-spawn lifetime setting. Commands, permissions, caps, lifecycle and M1–M7/K0 boundaries
are unchanged. The only production Java edits are AuraEffect, AuraRecipe and AuraSession; the build version is 0.8.0-k1.2.2.

This reduces requested white particles by 75% over complete four-tick periods. It makes no measured visual/performance
claim about native Minecraft. White points are omitted before M6 planning, reserving zero generation/placement budget
on quiet ticks. One global M6 plan and all original accounting equations, tier ceilings and deterministic fairness/
thinning remain. Simple's empty quiet variant uses existing SKIPPED_UNSUPPORTED with zero reservation and delivery;
the aura stays registered, so safety/expiry validation and the shared task continue. A disabled halo-only variant uses
existing planner outcomes. No skipped-white points are falsely counted as sends or failures. Other effects can use
freed budget. Under pressure halo allocation can improve without changing its cadence/geometry policy.

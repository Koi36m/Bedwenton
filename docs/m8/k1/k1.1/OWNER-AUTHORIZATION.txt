## Required visual changes

### 1. Replace the full waist ring with a rear-biased arc

The current bright white waist ring should no longer be a full 360° circle.

Change it into a **rear-weighted arc / crescent** that sits behind the player and follows the player's body yaw.

Requirements:
- keep the bright white END_ROD aesthetic
- the brightest / most visible part should be behind the player
- reduce the “solid glowing donut around the whole body” feeling
- the front of the player should be visually cleaner
- the arc should still read as a magical aura attached to the waist/back area
- it must rotate / animate consistently with the current aura timing model

Design guidance:
- Simple: clearly rear-biased, elegant, minimal
- Balanced: stronger rear arc with slightly fuller side presence
- Heavy: richer rear arc, possibly extending farther around the sides, but do NOT return to a full blunt 360° ring unless there is a very subtle front continuation

The result should feel like a magical support aura behind the player, not a thick circle surrounding them equally.

### 2. Refine the cyan halo to be cleaner and more elegant

The current cyan halo works, but should feel a little more refined.

Requirements:
- keep cyan DUST
- reduce cloud-like visual crowding
- if needed, slightly reduce density
- if needed, slightly raise the halo so it reads more cleanly
- avoid making it clash excessively with the player nameplate
- preserve the current concept of a small rotating halo above the head

### 3. Do not add new visual layers

For this polish pass:
- do NOT add orbiting spark nodes
- do NOT add trails
- do NOT add spiral behavior
- do NOT add new particle families
- do NOT add gyroscope / multi-ring complexity

This is a refinement pass, not a feature expansion.

## Performance / safety constraints

This is still a conservative visual effect.

Do not:
- add new scheduled tasks
- increase effect counts or capacities
- add unbounded state
- load chunks for effects
- broadcast particles globally
- introduce NMS
- introduce reflection-based hacks
- introduce any new dependency

Keep particle counts bounded and performance-conscious.

A small reduction in total particle density is acceptable if it produces a more elegant result.

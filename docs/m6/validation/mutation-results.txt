M6 R1 mutation analysis of the THROWAWAY reference implementation (not delivered).
58 hand-written mutants, each applied alone; the 49 M6 tests run (Java 25.0.4.1, Gradle 9.1.0).
"failing=N" is the number of failing tests, then their names (truncated to 40 characters).

Result: 56 killed, 2 survived. Both survivors are proven equivalent:
- M34 (`total <= r` -> `total < r`): when a role group's total T equals the remaining r, the proportional rule gives
  each batch floor(r n_b / T) = n_b with remainder 0, which is exactly "keep the whole group". The contract keeps the
  explicit case for readability; both readings give identical plans.
- M46 (selection without `% n`): o <= g - 1 and floor(j n / m) <= floor((m - 1) n / m) = n - g, so the index never
  reaches n. The modulus was redundant. The contract (section 7 step 7) now omits it and states the no-wrap lemma; the
  checker asserts that indices strictly increase. The reference was updated, and the final suite (412/412) ran after
  the change.

Test set used: the final 49 tests, minus three later edits made after this run: the import scan was relaxed to the
contract's `workshop.vfx.math.core.*` (it was stricter), expected indices dropped the redundant `% n`, and the checker
gained a strictly-increasing assertion (stricter). None of these can let a killed mutant survive except through the
relaxed import scan, which no mutant touches. Per-mutant logs stayed in the scratch directory.

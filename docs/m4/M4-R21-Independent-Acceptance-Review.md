## Technical review findings

**F4 (half-width underflow): addressed.** Contract §5.2 now integrates with the full interval width and halved Gauss weights rather than multiplying a weighted sum by an underflowing half-width. An independent evaluation of the specified arithmetic yields `G(0, MIN_VALUE) = MIN_VALUE` at speed 1, and `4.940656458412466e-224` at speed `1e100`. The new regression test `halfWidthUnderflow` tests subnormal parameter intervals, several speeds, and `lengthAt(nextUp(t0))`. `subnormalSpeedLongRange` addresses the secondary product-order mutation survivor.

**F5 (weighted-sum overflow/NaN): addressed.** Contract §§5.1–5.2 now use normalized speed pairs and a bounded accumulation with branched multiplication order. An independent spot check of its specified arithmetic with width `MIN_VALUE` and components `(1e308, 1e308, 0)` returns a finite `~6.9871e-16` rather than `NaN`; `MAX_VALUE` components also yielded finite values for this width. Regression tests cover high-component lines, a finite table with extreme derivative near its start, and randomized magnitude/range combinations. The full floating-point proof is presented in the specification; spot checks do not constitute a formal proof of every representable input.

**Original R1 issues F1–F3:** R2's tolerance floor, bounded ratio/linear partial-length modes, and explicit inversion cap-exit rules remain in R2.1. No regression in the design was identified in this review.

**Mutation evidence:** the package reports 55 mutations, 50 killed, four equivalent (M20, M33, M38, M45) and one tolerance-equivalent (M13). The summary and detailed mutation-result file are internally consistent. The temporary reference implementation and mutation harness were not included, so the actual 313/313 Java 25 execution and 55 mutation outcomes were **reviewed as supplied evidence, not independently rerun**. The decisive independent verification is still Codex's future M4 Java 25 production run, with GitHub Actions if its sandbox cannot run Gradle.

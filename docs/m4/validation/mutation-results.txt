M4 R2.1 mutation analysis against the THROWAWAY reference implementation of contract revision 2.1 (not delivered); Java 25.0.4.1.
Each mutant is one textual change (patterns in the review scratch harness), run against all M4 tests.
Procedure: a full run of all 55 mutants (the 47 R2 mutants, adapted where the panel rule changed, plus 8 R2.1 mutants)
with 58 M4 tests; then M4R21RegressionTest.subnormalSpeedLongRange was added for the survivor M50, and every survivor
was rerun against the final 59 tests. Tests were only added between the runs, so a mutant killed in the full run stays
killed.

Result: 55 mutants; 50 killed; 4 equivalent (M20, M33, M38, M45); 1 tolerance-equivalent (M13).

Survivors explained (unchanged from R2):
  M13 (partial integral not normalised by rho): changes results only inside the panel error estimate (rho = I2/I1 is
      within e_k/I1 of 1); detectable only by copying the algorithm. Item for the implementation review.
  M20 (Math.round instead of round half up): Java's Math.round is round half up for 0 <= q < 2^62 (contract 6.2).
  M33 (lengthAt(t0) special case removed): with k = 0, F_0(t0) = 0 and S_0 = 0, so the result is 0.0 anyway.
  M38 (r not clamped to I2): when distance - S_k exceeds I2_k, f_hi < 0 <= tolInv, and step 4 returns hi, exactly as
      with the clamp (f_hi = 0).
  M45 (no break at i = 63): the extra step forms only a midpoint (no Newton, no evaluation) and then the loop ends;
      the better end of the same bracket is returned.
R2.1 mutants: M48 (R2 arithmetic), M49 (always (d S) M), M50 (always d (M S) or (M d) S), M51 (no (M d) S branch),
M52 (branch on d S > 0), M53 (nu dropped), M54 (no zero-speed shortcut), M55 ((d S) M in place of (M d) S): all killed.
